<details open>
<summary><b>🏆 QUEST #01: MentorFlow API — Marketplace & Motor de Agendamento de Mentorias</b></summary>
<br>

```text
╔══════════════════════════════════════════════════════════════════════════════╗
║ ⚔️ BOSS DEFEATED: Concorrência, Double-Booking & Precisão Contábil           ║
║ 🛠️ LOOT / TECH: Java 21 • Spring Boot 3 • PostgreSQL • Docker • JUnit 5      ║
╚══════════════════════════════════════════════════════════════════════════════╝
```

🔗 **Repositório:** [github.com/geovanneenzo8-maker/mentorflow-api](https://github.com/geovanneenzo8-maker/mentorflow-api)

O **MentorFlow API** não é apenas um CRUD básico — foi projetado como um sistema real de produção para resolver desafios críticos de Engenharia de Software Back-end:

- 🔒 **Anti Double-Booking (`PESSIMISTIC_WRITE` + Idempotência):** Implementação de bloqueio pessimista no banco e `idempotencyKey` para impedir agendamentos simultâneos conflitantes (`HTTP 409 Conflict`).
- 💰 **Motor Financeiro de Split (85% / 15%) & Ledger Imutável:** Cálculos monetários exatos com `BigDecimal` (`RoundingMode.HALF_UP`), dividindo pagamentos automaticamente entre mentor e plataforma com registro em trilha contábil imutável (*Financial Ledger*).
- 🔄 **Máquina de Estados & Estorno Reverso Atômico (`@Transactional`):** Cancelamentos de sessões pagas revertem os saldos de forma 100% atômica, gravam `REFUND_DEBIT` no Ledger e liberam a agenda imediatamente.
- ⚡ **Zero N+1 & Testes E2E:** Consultas otimizadas em JPQL (`JOIN FETCH`), erros padronizados na **RFC 7807** e suíte completa de testes automatizados rodando em pipeline CI no GitHub Actions.

</details>
